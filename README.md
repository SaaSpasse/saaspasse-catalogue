# saaspasse-catalogue — archive

Le catalogue public est intégré dans
[saaspasse-app](https://github.com/SaaSpasse/saaspasse-app), à
[saaspasse.com/collaborer](https://saaspasse.com/collaborer). Les nouveaux travaux
sur les offres, les textes et le design se font dans
ce projet, sous `web/app/collaborer/`.

Ce dépôt conserve les anciens HTML et fiches produits 2026 comme historique.
Leurs prix, inclusions et disponibilités ne décrivent pas nécessairement l'offre
actuelle. `index.html` n'est plus la source du catalogue public.

L'ancien domaine `catalogue.saaspasse.com` reste utile pour les liens existants.
La branche `codex/catalogue-migration-release-20261002` conserve l'implémentation
Netlify de ses redirections et les manifests/tests de compatibilité. Préserver
cette infrastructure lors de toute maintenance de l'ancien hébergement.

Voir [CLAUDE.md](CLAUDE.md) pour les repères de travail.
